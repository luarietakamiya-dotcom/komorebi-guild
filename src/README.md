# 木もれびギルド

`index.html` をブラウザで開くと遊べます。インストール、通信、ビルドは不要です。週の初めに、リーダーが伝書で今週の行き先を知らせ、標準速度ではゲームを表示している実時間12秒後に出発します。町か伝書箱で「今週の自動判断を止める」を押すと、その週は手動で準備できます。ギルドホールでは隊ごとに、安全・報酬・薬草・鉱石・探索の深さ・倉庫の不足資源から優先条件を選べます。複数の依頼が候補に残ると、リーダーの性格が選択に影響します。

## 休暇と冒険者の歩み

- HP・MPは次の遠征に引き継ぎます。戦闘の能動技・手当てにはMPを2使います。週の変わり目に、町にいる仲間は最大値の20％、休暇を取った仲間は55％回復します（端数は切り上げ）。宿屋と食べ物屋があると、それぞれ5ポイント上乗せします。
- 仲間の残りHP・MPが少ない週や療養中の仲間がいる週は、リーダーが隊を休ませます。ホールの「今週は隊を休ませる」でも指示できます。休暇中の隊員は翌週まで出撃できません。
- 戦闘でHPが0になるたびに死亡回数が増えます。薬での復帰後も回数は残ります。担架で再戦して重度の捻挫を負うと、2週間後に復帰します。消失の1回前の戦闘不能や晶角イノシシによる戦闘不能では骨折し、4週間後に復帰します。錬金術師の店があれば骨折の復帰が1週間早まります。
- 通常は3回目、大聖堂がある間は5回目の死亡で永久消失し、隊は帰還します。消失1人につき信用が15点、英雄廟がある間は5点下がります（下限0）。名簿の「人物詳細・育成」から帰還済みの人物を引退させると、信用はそのままで町の住人になります。死亡・消失・引退の記録は帰還記録で読めます。

## 交友・結婚・世代交代

人物手帳の「好感度と家族」で親しい順に相手を確認できます。共闘、かばう、救出、同じ隊の休暇、酒場で過ごす週に好感度が上がります。町にいる相手にはペアごとに週1回、金庫から10Gで贈り物を渡せます。好感度40から同じ敵に続けて攻撃するとダメージが1増え、帰還時は動ける友人がいれば士気が1上がります。残りHPが半分以下の友人への攻撃を自主的にかばうこともあります。戦術オーダーのかばう構えを優先します。

好感度100で町にいる独身の成人同士は結婚できます。配偶者は自主的にかばう相手として優先され、どちらかが休暇を取って二人とも町にいれば、二人に休暇回復と士気＋2が付きます。引退した人の交友は名簿の「家系図と町の子供」から開けます。

結婚後、夫婦が町で週を迎えると18％の確率で子供が生まれます。次の出生までは2年以上空き、同じ夫婦が同時に育てる未成年は2人までです。子供は町で幼年期、少年期、見習いと育ちます。家系図で年齢や親を確認でき、種族ごとの成人年齢に達したら、週の最初の出発前に入団させられます。引退・消失・天寿の後も家系図と履歴にその名が残ります。

子供は親の種族・職系統・性格と得意な能力を受け継ぎます。その職系統では経験値が5％増えます。親に初期技以外の継承候補があれば35％の確率で1技の素質を持ちます。この家伝の技だけは転職前後を問わず習得でき、全職共通の3枠のうち1枠を使います。

「家系図と町の子供」の「1年の長さ」で1・4・13・52週を選べます。新しい町は4週、以前のセーブは52週で1年です。変更しても年齢や誕生日までの進み具合を引き継ぎ、工房の修業にも同じ年月が流れます。

## 職業と転職

自作冒険者は9つの下位職から登録します。人物手帳の「職業と転職」で、現在の職から進める候補と、ほかの職に就くために足りない条件を確認できます。中級12職はLv.2、上級12職はLv.5、レジェンド11職はLv.10からです。町では別の下位職や経験済みの職に移れます。固有職の人物は専用の職を続けます。

たとえばモンクから侍になれば禍津刀神を目指せます。剣聖も目指す場合は、剣士からフェンサーを経験し、侍に戻ると転職できます。忍者の直系はアギトです。聖女と聖人は同じ職で、性別未指定の場合は「聖者」と表示します。

技は現在の職で習得し、転職後も使えます。習得枠は生涯で3つです。家伝の技と大図書館・学院の先修には従来の規則が適用されます。

## 戦術オーダーと戦闘の見守り方

遠征パーティーの各隊員か、名簿の「人物詳細・育成」から「戦術オーダー」を開きます。条件・対象・行動を最大10件まで組み合わせ、上に置いたものから判定します。たとえば「リーダーのHPが40％以下 → リーダーに回復薬」を通常攻撃より上に置くと、薬が残っている間だけ回復を優先します。対象がいない場合、薬切れ、技の使用ラウンド前などは次の行を調べます。該当する行がなければ、習得技を含む従来の自動戦闘を行います。

「かばう」は、次の自分の手番までに指定した仲間への攻撃を1回引き受け、自分の防御で受けます。たとえば「ポポのHPが50％以下 → ポポをかばう」を「いつでも → 残HPが最も低い味方をかばう」より上にすると、ポポが弱ったときだけ優先します。自分自身、戦闘に参加できない仲間、すでに別の仲間がかばっている相手は対象から外れます。

「回復役」「攻撃役」でその人物の習得技に合わせた設定に置き換えられます。「盾役」は、かばえる仲間のうち残HPの割合が最も低い人が50％以下ならその人を、次にリーダーが75％以下ならリーダーをかばいます。どちらにも該当せず自分のHPが40％以下なら、自分に手当てします。適用後は条件や優先順を編集できます。

「大胆に進む」で水晶の鉱脈に入ると、苔イノシシに加え、詠唱で仲間を動揺させる晶角イノシシが現れます。動揺中は攻撃が3下がり、「動揺を鎮める」で回復します。

探索中はダンジョンの足元にHP、攻撃・手当ての対象にダメージや回復量を表示します。発動した規則と行動は戦闘欄と探索日誌に残ります。新しく出発する遠征は等速で約2秒に1歩、戦闘では約1秒に1手進みます。旧版で出発済みの遠征は、その帰還まで従来の歩調を引き継ぎます。

標準では、ゲームを表示している実時間4分で1週間が進みます。「遊び方」の「1週間の長さ」で2分・4分・8分を選べます。週の途中で切り替えても、それまでの進み具合を引き継ぎます。施設の生産と相談の期限もこの時計に従います。「全体を一時停止」で町・すべての隊・戦闘が止まり、相談への返信や戦術オーダー編集は続けられます。「隊を一時停止」と速度切替は表示中の隊だけに効きます。タブを隠している間やゲームを閉じている間は進みません。

町ではすれ違いの挨拶や鍛冶屋の呼び込みが、遠征では分岐や戦闘に応じた一言が人物の頭上に出ます。吹き出しは自動で消え、返信は不要です。「遊び方」の「町・遠征の会話吹き出し」で頻度を変更できます。初期設定は「控えめ」です。

## 複数隊の運営

- ギルドホールの「第2隊を開設」から増隊します。開設費は順に50・100・150・200Gです。各隊は1〜3人編成で、出発前の隊からは編成画面で移籍できます。シオンの雇用と自作冒険者の登録を済ませると、5隊を同時に送り出せます。
- 町の「今週の出発・帰還」かホールの隊名を押すと、その隊の依頼・探索・帰還報告を開きます。各隊は別々の依頼を受注し、速度と一時停止を個別に設定できます。受注済みの依頼は翌週に再掲されます。
- 分岐の相談は「伝書箱」に届きます。送信した隊だけが待機し、他隊は探索を続けます。返信する順番は自由です。戦闘不能の緊急通信が届くと該当する隊が表示され、全隊が待機します。どちらの相談にも翌週の返信期限があります。「返信せず翌週へ」で週を進めると、未返信の相談は各隊のリーダーが性格と探索方針に従って判断します。選んだ行動は伝書箱と探索日誌、帰還後は帰還記録にも残ります。受注した週限りの依頼は、週をまたぐと納品期限を過ぎます。
- 遠征ごとに納品・報酬・成長を処理し、納品後の素材はギルド倉庫に入ります。売却代金はギルド金庫に入り、工房への納品や手動注文にも倉庫の素材を使えます。在籍者全員の週給はその週最初に出発した隊の帳簿で精算します。雇用・登録は最初の出発前にできます。最後の隊が帰還したら週を締められます。
- 帰還時と週初め、町にいる隊は財布に運転資金100Gを残せる範囲で、一人につき一品まで装備を整えます。安全第一は防具、大胆は武器、素材優先は魔法具を好みます。盾役は防具、術師は魔法具、それ以外は武器を好み、方針と職業に合う枠のうち今の装備が弱い人を優先します。隊が購入する場合は素材込みの代金を払い、品名・装備者・金額が帰還報告か週初めの伝書に残ります。帰還時は購入後も100Gを超えた分を金庫に戻します。
- 日単位のセーブも同じ保存先から再開できます。旧版の第8日は第8週として扱い、編成、探索地点、週内の経過割合、返信・復帰までの残りターン数、帰還報告を引き継ぎます。

## 階級・昇級試験・一般冒険者

ギルドホールの「ギルド設定」で、階級を低い順に1行ずつ登録します。所属冒険者と一般冒険者は同じ段位を使います。呼称を変えても取得済みの段位は残ります。段数を減らすと表示と受注資格は現在の最上段までになり、段数を戻すと以前の段位が再び有効になります。隊員全員が依頼と行き先の必要階級を満たすと出発できます。

人物手帳または一般冒険者の登録票から、週1回、次の段への試験を受けられます。受験資格はレベルか依頼への参加回数で決まります。試験の重点と厳しさはギルド設定で選べます。合否は本人の履歴に残り、厳しい試験に合格するほど名声が上がります。

ホールと名簿で、今週訪れた一般冒険者に会えます。来訪者は複数のギルドを行き来し、名声が上がると人数が増えます。週の後半には階級に応じた依頼で出発し、週を締めると町に分け前を納めます。「町に届いた分け前」から金庫と倉庫へ移せます。週の前半に支度金を提示すると専属契約を交渉できます。信用・名声と、その人がこの町で終えた仕事の数も交渉に効きます。

剣豪シュウサイ、姫騎士ユーリア、退魔忍リィナ、巫女ユキナなど、固有の人物には専用の職業と技があります。特別な来訪の間隔は全員共通で、最短12週です。名声条件を満たす候補のうち、初対面の人、次に前回の訪問が古い人の順に訪れます。来訪した週は町と伝書箱に「特別な来訪」の伝書が届きます。出会いと契約の条件は「訪問のうわさ」で読めます。加入の記録は人物手帳と帰還記録に残ります。

リィナは名声16以上で来訪候補になり、初めて訪れた週に伝書を届けます。「苔むす森の洞」を踏破すると、ホールで専属契約を交渉できます。固有技「破邪の印」の威力は精神に応じて上がります。封じ札は「呪いの祭壇」でリィナ自身が受ける封印の呪いを防ぎます。

ユキナは名声18以上で来訪候補になり、初めて訪れた週に薬草と伝書を届けます。町で錬金術師の店が営業していると専属契約を交渉できます。「鈴の祈り」は魔力に応じて味方ひとりのHPを回復します。ユキナが行動できる間は、呪いの祭壇で自分や同行者が新たに受ける「封印の呪い」「鈍重の呪い」を、1件につきMP2で自動的に祓います。

踊り子メニーヤは名声17以上で来訪候補になり、同じ遠征から2人以上が無事に帰還したギルドと契約します。「霞扇の舞」は器用さが威力に乗る扇技で、惑わせた敵の次の一撃を最大4ダメージ軽減します。街道や広場の最終ラインでも使えます。「誘いの輪舞」を習得すると仲間の行動順を早められます。

## ギルドランク

ギルドホールで、次のランクに必要な条件と、週ごとの偉業ポイントの内訳を確認できます。ダンジョン踏破は5点、最深層の番獣討伐は6点、襲撃の撃退は4点、襲撃のヌシ討伐は6点、昇級試験の合格は3点です。番獣を倒して踏破すれば、両方の点が入ります。

## レビュー §3 について初版で決めたこと

- **依頼と所有**　出発と同時に1件を受注。期限はその週の帰還まで。新たに持ち帰った品だけで判定し、達成時だけ必要数を全量納品。撤退でも同じ基準。未達なら報酬・納品はゼロで、荷物はすべて余剰。各隊が出発できるのは週に1回で、同じ週の再受注はできません。毎週新しい掲示として再受注可能。倉庫の余剰は翌週も保持。帰還処理は探索状態から1回だけ行う。初帰還をトトがマルタに知らせ、成功・失敗を問わず翌週から上位注文を掲示。
- **時間と経済**　準備中と回答待ちの隊は待機。緊急通信では全隊が停止。移動先の処理と自動戦闘を1歩に含め、戦闘中の着信はその打撃で中断する。出発時に食料を人数×10Gで買って消費し、薬を1本30Gで用意。未使用薬は帰還時に同額で返品。在籍全員（控え・療養中を含む）に週給10＋出発時Lv×2Gを帰還時に支払う。報酬の30%（切り捨て）を追加分配。素材売上は分配対象外。見積りは達成・携行薬すべて使用・売却前。装備は全員普通武器、倍率1.0。初期在庫はゼロ。雇用費＝50G×応募者Lv。自作枠は登録無料で以後は通常給与。無理な買物・補給は不可。支払い義務は帳簿に負残高として残せる。遠征を休んで町を手伝えば、週給相当の委託料＋30Gを得て、支給後に30Gが残る。
- **分岐と通信**　野原で薬草2（狩人同行で＋1）。採集路では薬草2・鉱石1。近道は敵2戦、勝利ごとに鉱石2。安全第一は無戦闘の採集路を選ぶ。素材優先は両路に有用素材があり判断を保留。慎重・臆病・仲間思いは通信、大胆は自ら近道へ。「任せる」は大胆なら近道、他は採集路。通常通信は1遠征1回、同種4歩間隔。危機は敵の打撃で誰かのHPが0になった瞬間。1回の転倒に1回必ず通信し、通常枠・間隔を無視。返信時の「任せる」は大胆なら担いで進む（全員倒れていれば帰還）、他は帰還。任せた結果、方針、自律行動、収穫を同じ日誌に記録。
- **戦闘**　苔イノシシはHP13／攻31／防4／速10。味方は設計書の職業初期HP・攻・防・速を使用。速の降順、同速は編成順、敵は同速の味方の後。敵の標的は残HP最少の行動可能な仲間、同値は編成順。ダメージ＝max(1, floor(攻×武器倍率−相手の防×0.5))。敵倍率1。10ラウンド引き分けは安全帰還。敵撃破時のみ鉱石獲得。
- **負傷・療養**　HP0で戦闘不能。薬1本で対象をHP16（最大HPまで）に戻してその場で続行。担ぐには動ける仲間が必要で、本人は行動不能。次の別の戦闘開始時に重傷へ移る。帰還は常に成功。戦闘不能のまま帰れば翌週復帰、重傷なら翌週いっぱい療養し翌々週に復帰。現在の死亡回数と大怪我の扱いは「休暇と冒険者の歩み」を参照。
- **成長・研究**　全帰還者に経験値2＋勝利数×2＋達成時4。必要経験値＝20×現在Lv²。レベルごとに初期能力の10%ずつ加算し切り捨て。初めて余剰鉱石を1個卸すと即研究完了、翌週から木洩れ日の刃を80Gで購入できる。攻撃倍率1.3、1本を準備中に付替え可能。鉱石売値24G、薬草10G。卸しは無償。
- **観測指標**　実力は初期0で勝利×2＋依頼達成3（上位は6）を加点。信用は精算した直近20件の達成率（四捨五入、0件時50）。生存率は100から重傷発生時に1人3点減点する安全の目安。満足度は60から達成分配で2点加点、帰還時の戦闘不能・重傷1人につき2点減点。実力・生存率・満足度は0〜100に収め、冒険者の階級が依頼と行き先の条件になる。

## 操作と保存

- 出発時は×1（約2秒で1歩）です。「速度」で×2（約1秒で1歩）と×1を切り替えられます。地図や日誌を読みたいときは「一時停止」を押し、「再開」で続きを見守ります。「帰還する」を押すと、その場で遠征を切り上げて精算します。
- 分岐の相談には伝書箱から、戦闘不能の緊急通信には割り込み画面から返信します。続行を指示すると同じ速度で自動探索が再開します。通信から帰還を指示することもできます。
- 初週に通信を試すには、「洞窟のきらめき鉱石」を選び、ガルドをリーダーにして「素材優先」で出発します。分岐で近道を指示すると、初期編成ではポポが最初の敵の打撃で倒れます。薬を持たせた場合と、担いだ場合を比べられます。
- 自作冒険者は「冒険者名簿」から登録します。PNG・JPEG・WebPの画像は中央を正方形に切り抜き、256×256で保存します。画像を省くと、選んだ職業・性別・髪色に対応した顔絵を使います。出発準備で既存メンバーのチェックを外し、自作冒険者を加えてリーダーに任命できます。「編成を保存」でいったんホールに戻ることもできます。
- 自動の1歩ごと、操作のたびにブラウザの `localStorage` に保存します。同じファイルを同じブラウザで開き直すと、探索中は保存した地点・速度から動き出します。一時停止中は「再開」まで、着信中は返信までその場で待ちます。ローカルファイルの保存可否はブラウザ設定に依存し、保存できない場合は画面に表示します。画像を含むデータは端末内で扱います。

## 既知の制限

- 遠征は最大5隊、所属冒険者向けの掲示は最大11依頼です。上位注文の解放後も週を重ねて遊べます。世界一のギルドを決める判定や期間制限はありません。
- 分岐では性格と方針を使い、戦闘では好感度に応じて自主的にかばうことがあります。4つの性格、職業別の固定能力、狩人の採集補正を実装しています。個別の戦闘スキルは人物手帳で習得できます。
- 自作は1人・顔絵1枚。保存は1ブラウザ・1スロット・1タブでの利用を想定しています。別端末への移行や同時編集には対応していません。

## 街の区画と建築

[町のホーム](index.html) の区画図で空きのある区画を選び、建築カタログの施設を押すと、表示額で建築します。果樹の丘・小川のほとり・風車通り・クローバー平原では2軒まで建築できます。どちらの地図でも各施設は単独時と同じ大きさで表示されます。ほかの区画の新築は1軒までです。以前のセーブで既に建てた2軒はそのまま利用できます。「容量 1/2」はあと1軒建てられる表示です。2軒目も同じカタログから選び、同じ種類の施設も独立して機能します。完成した施設を選ぶと効果を確認できます。

### 街道の防衛

見張り塔は中射程の射撃、バリスタ台は長射程の重い一撃、魔法塔は範囲攻撃、バリケードは足止めを担当します。建築費は900〜2,200 Gです。区画を選ぶと街道と射程を重ねて確認できます。施設はLv.5まで強化でき、種類ごとの追加装備を1つ取り付けられます。破損した施設は「町の復旧」から修理できます。

予告が届いたら、守備隊員の持ち場を街道の要点・町の入口・広場から選びます。未指定なら自動配置です。襲撃中は自動で迎撃し、広場では各人の能力と戦術オーダーで戦います。最終ラインが破られると、侵攻路沿いの建物とホールに被害が及びます。結果は「直近の防衛報告」と履歴に残ります。

### 見晴らしの丘

町の右上にある「見晴らしの丘」を選ぶと、8種類の特殊建造物の効果を比較できます。通常の区画を使わず、ギルド金庫から3,600 Gで1棟を建築できます。別の建造物への建て替えは5,400 Gです。水彩地図と立体地形のどちらからでも操作できます。

地下水路や大書庫には罠があり、盗賊・ドルイド・獣使いが感知できます。天文台があれば、どの職業でも感知できます。大書庫の転送罠で行方不明者が出ると隊は救出を待って帰還します。お城があれば騎士団が最初の1手で到着します。欠損や呪いが残った仲間は、帰還後に人物手帳の「健康と引退」から義肢の注文や大聖堂での治療を選べます。

罠を感知できなかった場合は、行動できる隊員ごとに判定します。難しいダンジョンほど罠にかかりやすく、かかった隊員には1％でモンスターハウスによる死亡、3％で触手トラップによる妊娠が発生します。ほかは部屋の仕掛けに応じて、欠損、精神崩壊、呪い、転送、捕縛、荷物の損傷・没収が起きます。

ゴブリン・オーク・人の盗賊が残っている戦闘で全滅すると、生存者は捕縛されます。捕縛のガス室でも救助要請が届きます。遠征隊の欄か伝書箱から救助隊を派遣してください。猶予は捕縛から6手、到着は派遣から通常3手、お城があれば1手です。猶予を過ぎた時点で、捕虜ごとに一度だけ被害を判定します。死亡率は2％、生存者が欠損または精神崩壊を負う確率は30％です。女性の生存者には独立して30％の妊娠判定もあります。

ゴブリンの攻撃で戦闘不能になると1％、オークでは10％で妊娠療養に入ります。遠征と町の防衛への復帰は発症から12週後です。大聖堂では120 Gで発症から4週に短縮できます。この療養から子供は生まれません。精神崩壊は大聖堂で治療を始めてから4週で回復します。ホールのからくり工房では、25 Gで部位に合った義肢を注文できます。欠損した部位に関係する2能力は基礎値の50％になり、義肢は職人の腕と品質に応じて5〜80ポイントを加算します。

## 水彩の地面と景観スプライト

町の地面は[水彩試作](../art/media-generation-komorebi-land-watercolor-0-0fa7da69-c7ff-46ef-81b0-06dece62894a.webp)を参照地の1393×784pxに合わせて使います。建物の足元と住人の経路は参照地と同じ位置です。[ダンジョンの確認画像](test/dungeon-watercolor.webp)には、水彩の洞と隊列が歩く2本の分岐道を収録しています。どちらの確認画像もゲームのCanvas描画命令をCairoで再生したものです。

内蔵のimagegenで「参照の町に合わせて斜め上から見下ろし、屋根や天面を広く、壁を短く描く。透明水彩の紙目とにじみを残し、左上からの温かい光、足元の淡い影や草を添える。各品を透過背景の3列×3行に独立して描く」と指定しました。原画は[施設](../art/watercolor/buildings.webp)、[町の小物・植栽](../art/watercolor/village.webp)、[洞窟の景観](../art/watercolor/dungeon.webp)の3枚です。[洞の背景](../art/watercolor/grotto.webp)は町の水彩試作と旧版の洞を参照し、上部の木の根と岩のアーチから平らな探索路に光が差す構図にしました。

配布用の `assets/scenery_*.webp` は各276×306pxの透過画像です。切り分けスクリプトが足元をそろえ、アルファチャンネルからタップ用の輪郭を生成します。住人の前後関係と畑の反復配置はゲームの描画側で決まります。素材の再生成にはPython 3、Pillow、NumPy、SciPyを使います。

```sh
python3 game/tools/scenery-watercolor.py         # 原画から景観27種とタップ用の輪郭を生成
python3 game/tools/scenery-ground.py              # 水彩の町と洞の地面を生成
python3 game/tools/scenery-ground.py --town-only  # 町の地面だけを生成
python3 build-single-file.py                     # 配布用の単一HTMLを再ビルド
```

旧版の水平断面モデルは[4方向の資料](test/scenery/index.html)で閲覧できます。
